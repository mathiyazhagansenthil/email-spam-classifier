# Email Spam Classifier

Classifies emails as spam or not spam using NLP and machine learning.

## Dataset
Enron email spam dataset (spam_ham_dataset.csv)

## What I did
- Preprocessed text: lowercased, removed punctuation, removed stopwords, applied stemming
- Converted text to numerical features using CountVectorizer
- Trained a Random Forest classifier
- Tested on custom example messages

## Results
Accuracy: 98.4%

## Tech used
Python, pandas, NLTK, scikit-learn

## How to run
Open the notebook in Jupyter and run all cells.
